# Change boundary

The behavior gap lives in project workflow handoff rules, Codex skill discovery
and invocation metadata, and the Trellis Other publication backend. Keep Matt
methodology in genuine installed skills. Preserve .claude source bytes and the
Trellis runtime parser/step IDs. Prefer documented project metadata to hooks or
global settings. Add a reproducible local adapter only if experiments require it.

Validate baseline, minimal change, real execution, simplification, regression.
Use native delegation with explicit task paths, ownership and coordinator-only
lifecycle writes. Reuse actual check evidence; do not impose a second review
pipeline. No external publication, dependency on OMC, or application changes.
